# Flowex

AI-видеоредактор, работающий целиком в браузере. Описываете ролик текстом — ИИ генерирует интерактивную сцену на Canvas 2D (HTML/CSS/JS), приложение рендерит её на таймлайне и экспортирует в видеофайл со звуком.

---

## Как это работает

1. **Выбираете стиль** — из готовых пресетов (кино, минимализм, ретро, неон и др.) или пишете свой промпт.
2. **Прикрепляете файлы** — фото, видео, музыку, голосовые заметки. ИИ автоматически подставит их в сцену.
3. **Описываете ролик** — «Сделай 10-секундный трейлер про космос с частицами и драматичной музыкой».
4. **Редактируете** — меняете длительность сцен, цвета, тексты, параметры в Инспекторе без запросов к ИИ.
5. **Экспортируете** — видео с аудиодорожкой сохраняется прямо на компьютер.

## Возможности

### Генерация видео
- Полная интеграция с LLM: OpenRouter, OpenAI, Gemini, Mistral, Anthropic, Groq, DeepSeek, Ollama и любые OpenAI-совместимые провайдеры.
- Расширенный системный промпт с библиотекой FX: раскадровка, переходы, типографика, частицы, Ken Burns, аудио-визуализация.
- 10 готовых стилей (кино, минимализм, ретро, неон, корп и др.).

### Таймлайн и редактирование
- Интерактивный таймлайн с превью-кадрами и аудиодорожками.
- Перетаскивание границ сцен для изменения длительности.
- Разрезание клипов (split) по позиции playhead.
- Скорость воспроизведения: 0.25× — 3×.
- Вырезание аудио-клипов: перетаскивание краёв, split, drag.

### Ассеты и медиа
- Прикрепление фото/видео/звука к проекту.
- Индексация в IndexedDB — файлы сохраняются между сессиями.
- Автоматическое определение размеров изображений и видео.
- Запись голоса с микрофона (MediaRecorder API).

### Ручное редактирование
- **Инспектор CONFIG** — доступ ко всем переменным сцены: цвета (color picker), числа, строки, булевы значения.
- **Строковый парсер сцен** — перемещение, удаление, изменение длительности сцен без запросов к ИИ.
- Навигация по таймлайну: Space (play/pause), стрелки (±1 сек), Shift+стрелки (±5 сек).

### Экспорт
- Рендеринг прямо в браузере через MediaRecorder + canvas.captureStream.
- Запись аудио с импортированных файлов и записей микрофона.
- Поддержка видео любой длительности.

### Безопасность и приватность
- API-ключи хранятся только в браузере (localStorage).
- Уходят напрямую выбранному провайдеру — сервер не видит ключи.
- Проекты сохраняются локально, ничего не уходит на внешние серверы.

## Быстрый старт

Требуется [Bun](https://bun.sh) (или Node.js 20+ с npm/pnpm):

```sh
git clone https://github.com/mawwki/flowex-ai.git
cd flowex-ai
bun install
bun run dev
```

Откройте http://localhost:5173 и начните создавать видео.

### Другие команды

| Команда         | Описание                                      |
|-----------------|-----------------------------------------------|
| `bun run dev`   | Дев-сервер с HMR                              |
| `bun run build` | Продакшен-сборка (`.output`)                  |
| `bun run preview` | Предпросмотр продакшен-сборки               |
| `bun x tsc --noEmit` | Проверка типов (строгий tsconfig)       |
| `bun run lint`  | ESLint + Prettier проверка                     |
| `bun run format`| Автоформатирование кода                        |

## Структура проекта

```
src/
├── routes/
│   └── index.tsx          ← главный экран приложения
├── components/flowex/
│   ├── Preview.tsx        ← плеер (iframe с Canvas 2D)
│   ├── Timeline.tsx       ← таймлайн с аудиодорожками
│   ├── PromptBar.tsx      ← строка запроса к ИИ
│   ├── PlaybackBar.tsx    ← управление воспроизведением
│   ├── Sidebar.tsx        ← список проектов + поиск
│   ├── Inspector.tsx      ← ручное редактирование параметров сцены
│   ├── StylePicker.tsx    ← выбор стиля перед созданием
│   ├── SettingsDialog.tsx ← настройки API-ключей
│   └── CodePanel.tsx      ← просмотр кода сцены
├── lib/flowex/
│   ├── providers.ts       ← провайдеры LLM + системный промпт
│   ├── fx.ts              ← библиотека FX (раскадровка, частицы и др.)
│   ├── stage.ts           ← песочница для выполнения кода сцены
│   ├── export.ts          ← экспорт видео в браузере
│   ├── media.ts           ← обработка файлов, запись голоса
│   ├── scenes-edit.ts     ← парсер/мутатор строковых сцен
│   ├── idb.ts             ← IndexedDB для хранения медиа-файлов
│   ├── store.ts           ← Zustand-стор проектов и настроек
│   └── types.ts           ← TypeScript-типы
└── styles.css             ← дизайн-система (oklch-палитра, анимации, утилиты)
```

## Технологии

- **TanStack Start** — SSR-фреймворк на React 19
- **Vite 8** — сборка с HMR
- **Tailwind CSS 4** — утилитарный CSS с oklch-палитрой
- **Zustand** — стейт-менеджмент
- **Lucide React** — иконки
- **Canvas 2D** — рендеринг сцен
- **MediaRecorder** — экспорт видео
- **IndexedDB** — хранение медиа-файлов
