# Pixel Weaver

Создай сайт с помощью которого ии может делать видео помощью кода (на HTML CSS JS), добавь возможность менять стили, переключатся между проектами, менять провайдеров и модели в настройках и под полем ввода. Сделай всё как на картинке, весь дизайн и вообще всё, все кнопки, переключение между проектами, настройки, выбор провайдеров (Mistral, Gemini, openAI, openrouter и другие) сделай редактирование видео, чтобы видео можно было скачать, и чтобы оно сохранялось даже при перезаходе, и всеебще все,сделай всё что нужно для этого веб приложения, максимально готовый продукт, все как на картинке, 1 в 1
