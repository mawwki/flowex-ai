# Flowex

AI-видеоредактор в браузере: описываете ролик текстом — ИИ пишет сцену на Canvas 2D
(HTML/CSS/JS), приложение рендерит её на таймлайне и экспортирует в видеофайл.

## Возможности

- Генерация и редактирование видео через LLM (OpenRouter, OpenAI, Gemini, Mistral,
  Anthropic, Groq, DeepSeek, Ollama или любой OpenAI-совместимый провайдер).
- Библиотека FX для ИИ: раскадровка, переходы, типографика, частицы, Ken Burns и т.д.
- Таймлайн с превью-кадрами, аудиодорожками, озвучкой с микрофона.
- Прикрепление своих фото/видео/музыки и указание ИИ, что с ними делать.
- Ручной контроль сцены: Инспектор CONFIG (цвета, тексты, параметры) без запросов к ИИ.
- Выбор стиля перед созданием проекта, выбор модели под полем ввода.
- Экспорт видео (включая звук) прямо в браузере, проекты сохраняются локально.

## Разработка

Нужен [Bun](https://bun.sh) (или Node.js 20+ с npm/pnpm):

```sh
bun install
bun run dev
```

Другие команды:

```sh
bun run build    # продакшен-сборка (.output)
bun run preview  # предпросмотр сборки
bun run lint     # eslint + prettier
bun run format   # автоформатирование
```

Ключи API хранятся только в браузере пользователя (localStorage) и уходят напрямую выбранному провайдеру.

## Структура

- `src/routes/index.tsx` — главный экран приложения.
- `src/components/flowex/` — UI: плеер, таймлайн, строка запроса, стили, инспектор.
- `src/lib/flowex/` — ядро: системный промпт (`providers.ts`), FX-рантайм (`fx.ts`),
  песочница сцены (`stage.ts`), экспорт (`export.ts`), ассеты (`media.ts`, `idb.ts`).
